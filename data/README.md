# Data

The raw data is not stored in this repository.

## How to get it
1. Create a free Kaggle account.
2. Download the "Brazilian E-Commerce Public Dataset by Olist": https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
3. Unzip it and place all 9 CSV files in `data/raw/`.

## Folders
- `raw/`       original CSV files, never edited
- `processed/` cleaned files created by the notebooks
